# Blog Login App

A React blog application with user authentication, built with React 19, React Router v7, and Vite.

---

## Features

- User login and authentication flow
- Client-side routing with React Router v7
- Icon support via React Icons
- ESLint configured for React hooks and fast refresh
- Responsive UI with custom CSS

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)
- npm

### Installation

```bash
git clone https://github.com/ziiodyne/blog-login-app-final.git
cd blog-login-app-final
npm install
```

### Running Locally

```bash
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173) in your browser.

### Linting

```bash
npm run lint
```

### Building for Production

```bash
npm run build
```

Output goes to the `dist/` folder.

### Preview the Build

```bash
npm run preview
```
